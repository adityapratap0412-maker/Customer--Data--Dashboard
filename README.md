# Customer Data Dashboard 📊

## 📌 Project Overview

This project is an interactive Customer Data Dashboard created using Microsoft Excel.

The dashboard helps analyze customer service data and provides meaningful insights into agent performance, contact types, ratings, and daily contact trends.

## 📊 Dashboard Insights

- Average rating of agents
- Contact type analysis
- Number of contacts
- Day-wise average ratings
- Day-wise contact analysis
- Customer service performance insights

## 🛠️ Tools & Skills Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Visualization
- Dashboard Design
- Data Analysis
